# 轻量团队云盘

Node.js + Express 单进程应用，面向 20 人以内的小团队。账号和文件元数据保存在本地 JSON 文件中，文件直接写入磁盘，不把文件内容载入服务内存；批量 ZIP 下载使用流式压缩。

## 启动

需要 Node.js 18 或更高版本。首次启动前设置管理员账号和至少 8 位密码：

```sh
export ADMIN_USERNAME='管理员账号'
export ADMIN_PASSWORD='替换为至少12位的随机密码'
npm install --omit=dev
npm start
```

服务默认监听 `6060` 端口，可用 `PORT` 环境变量修改。首次运行会创建管理员；之后账号保存在 `data/users.json`，修改环境变量不会重置现有管理员密码。

首次创建的管理员是超级管理员，只有超级管理员可以授予或取消管理员角色；其他管理员不能停用或取消超级管理员的权限。登录需要输入图形验证码。

每位成员可收藏个人文件和团队共享文件；登录后会显示团队公告，管理员可从左下角“消息”面板编辑公告。

如果应用在反向代理后面，只有在代理会覆盖并可信地传递客户端地址时，才设置 `TRUST_PROXY_HOPS` 为代理层数。

## 数据

- `uploads/`：文件内容。
- `data/users.json`：账号、角色和密码哈希。
- `data/files.json`：文件所属空间、上传者、备注及成员收藏状态。
- `data/announcement.json`：当前团队公告。
- `data/shares.json`：文件分享链接的摘要、提取码哈希和过期时间。
- `data/audit.json`：最近 3000 条登录和文件/账号操作记录，仅超级管理员可查阅。
- 每个账号默认有 1 GB 容量；管理员可按成员调整。团队共享和个人空间的文件都计入上传者额度，达到 80% 时界面提醒，超出额度的上传会被拒绝。
- 文件管理页可按文件名搜索当前空间，结果支持原有排序和分页。
- 团队空间文件所有成员可查看；只有上传者和管理员可删除或修改备注。个人空间只有文件所有者可查看。
- 文件可以生成 1–720 小时有效的分享链接，默认 24 小时；访客输入 8 位提取码后下载。提取码只保存哈希，分享令牌只保存摘要。
- 原版本 `uploads/` 中的文件会在首次升级启动时自动登记到团队空间。

备份时应同时复制 `uploads/` 和 `data/`。不要把这两个目录提交到代码仓库。
